HTML a CSS — příručka s příklady

Vše na této stránce je živá ukázka. Každý blok ukazuje kód a hned pod ním, co dělá.

1. Struktura stránky

Každá HTML stránka má pevnou kostru. Nejdůležitější je <head> (nastavení, nevidíš ho) a <body> (co se zobrazí).

<!DOCTYPE html>          <!-- říká prohlížeči: tohle je HTML5 -->
<html lang="en">          <!-- jazyk stránky -->
  <head>
    <meta charset="UTF-8" />                            <!-- diakritika -->
    <meta name="viewport" content="width=device-width" /> <!-- mobil -->
    <title>Název v záložce</title>
    <link rel="stylesheet" href="styles.css" />          <!-- připojení CSS -->
  </head>
  <body>
    ... obsah, který vidíš ...
  </body>
</html>
Zapamatuj: <link rel="stylesheet"> připojí externí CSS soubor. Bez něj by stránka byla bez stylů.

2. Základní textové tagy

<h1>Nadpis největší</h1>   <!-- h1 až h6: nadpisy podle důležitosti -->
<p>Odstavec textu.</p>        <!-- p = paragraph, běžný text -->
<strong>Důležité</strong>   <!-- tučně (má význam) -->
<em>zdůrazněné</em>          <!-- kurzíva (má význam) -->
Výsledek:

Nadpis (h3)

Odstavec s tučným a kurzívovým slovem.

Proč h1, h2, h3? Nadpisy mají být v pořadí (jeden h1, pak h2…). Pomáhá to čtečkám obrazovky a Google vyhledávání. Nedělej z běžného textu nadpis jen kvůli velikosti — velikost řeší CSS.

3. Sémantické značky (významové bloky)

Místo samých <div> používej značky, které popisují, co blok je:

<header>  horní lišta / hlavička
<nav>     menu s odkazy
<main>    hlavní obsah stránky (jen jednou)
<section> samostatná sekce (např. "Služby")
<article> samostatný článek / karta
<footer>  patička dole
<blockquote> citát
Přínos: Kód je čitelnější a stroje (Google, čtečky) stránce lépe rozumí. Vizuálně se nic nemění — to dělá CSS.

4. Atributy — doplňky tagů

Atribut je název="hodnota" uvnitř otevíracího tagu. Nejpoužívanější:

<a href="https://google.com">Odkaz</a>
   ↑ href = kam odkaz vede

<img src="foto.png" alt="Popis obrázku" />
   ↑ src = cesta k souboru     ↑ alt = text, když se obrázek nenačte

<div class="karta" id="hlavni">
   ↑ class = skupina (může být vícekrát)  ↑ id = jedinečné jméno (jen jednou)
class vs id: class používej pro stylování (může se opakovat), id pro odkazování jedinečného prvku nebo kotvy (#book).

5. Odkazy a tlačítka

<a href="#sluzby">Skoč na sekci</a>     <!-- # = odkaz uvnitř stránky -->
<a href="kontakt.html">Jiná stránka</a>

<button type="button">Klikni</button>  <!-- tlačítko (akce) -->
Výsledek:
Přejít na carousel
a vs button: <a> = někam vede (odkaz). <button> = něco spustí. V carouselu používáme <label>, což je třetí varianta — viz část o carouselu.

6. Obrázky

<img src="assets/foto.png"
     alt="Pracovník radí klientovi"
     width="429" height="411" />
  • src — cesta (relativní assets/foto.png funguje i po přesunu).
  • alt — popis pro nevidomé a když se obrázek nenačte. Prázdný alt="" = dekorativní obrázek.
  • width/height — pomáhají prohlížeči rezervovat místo (stránka „neposkakuje“).

7. Selektor a pravidlo

CSS pravidlo má tvar selektor { vlastnost: hodnota; }. Selektor vybírá, na co se to použije.

.karta      { color: red; }   /* .třída  = všechny prvky s class="karta" */
#hlavni     { color: blue; }  /* #id     = prvek s id="hlavni" */
p           { color: green; } /* tag     = všechny <p> */
.card__title{ font-size: 40px; } /* jméno s __ = část komponenty (BEM) */
BEM (naše konvence): blok__část a blok--varianta. Např. .card__title = nadpis uvnitř karty, .btn--dark = tmavá varianta tlačítka. Drží to názvy přehledné.

8. Box model

Každý prvek je obdélník složený z vrstev: obsah → padding (vnitřní odsazení) → border (rámeček) → margin (vnější odsazení).

.box {
  padding: 20px;           /* místo UVNITŘ, mezi obsahem a okrajem */
  border: 1px solid #ccc;  /* rámeček */
  margin: 10px;            /* místo VENKU, mezi prvky */
  border-radius: 20px;     /* zakulacení rohů */
}
padding vs margin (vnější = světle, vnitřní = zeleně):
Obsah s paddingem 20px
box-sizing: border-box (nastaveno v resetu) znamená, že width: 300px platí i s paddingem a borderem — bez toho by se šířka počítala divně.

padding-block a padding-inline

.box {
  padding-block: 100px;   /* nahoře a dole (svisle) */
  padding-inline: 40px;   /* vlevo a vpravo (vodorovně) */
}
/* Je to to samé jako zkráceně: */
.box { padding: 100px 40px; }  /* první číslo = svisle, druhé = vodorovně */

9. Flexbox — rozvržení do řady/sloupce

display: flex z prvku udělá „kontejner“, jehož děti se seřadí vedle sebe (nebo pod sebe).

.rada {
  display: flex;
  flex-direction: row;      /* row = vedle sebe (výchozí) */
                            /* column = pod sebe */
  gap: 20px;                /* mezera mezi dětmi */
  align-items: center;      /* svislé zarovnání dětí */
  justify-content: center;  /* vodorovné zarovnání dětí */
}

Nejdůležitější trik: flex: 1 1 0 na dítěti = „roztáhni se a zaber stejně místa jako sourozenci“. Používáme to u hero (text se roztáhne, obrázek zůstane vpravo) a u service karet.

Zarovnání

/* svislá osa (když je flex-direction: row) */
align-items: flex-start | center | stretch;

/* vodorovná osa */
justify-content: flex-start | center | space-between;
space-between: první dítě vlevo, poslední vpravo, mezera mezi nimi. Tím jsme dali „Services“ vlevo a tlačítko vpravo ve footeru.

10. gap vs padding vs margin

  • gap: 20px — mezera mezi dětmi flex kontejneru.
  • padding — mezera uvnitř prvku (mezi okrajem a obsahem).
  • margin — mezera vně prvku (odsazení od sousedů).
Tip: Pro rozestupy mezi položkami preferuj gap — nepotřebuješ řešit „poslední prvek ať nemá margin“.

11. Text, barvy a pozadí

.titulek {
  font-family: "Work Sans", sans-serif; /* písmo (s náhradou) */
  font-size: 80px;        /* velikost */
  font-weight: 400;       /* tloušťka: 400 = regular, 500 = medium, 700 = bold */
  line-height: 1;         /* výška řádku (1 = 100 % velikosti) */
  letter-spacing: -0.08em;/* mezera mezi písmeny (záporná = u sebe) */
  color: #2e4f21;         /* barva textu */
  text-align: center;     /* zarovnání: left | center | right */
  background: #a0f1bd;    /* barva pozadí */
}

Barvy se zapisují jako hex (#2e4f21), rgb(46, 79, 33) nebo rgba(0,0,0,0.5) (poslední číslo = průhlednost 0–1).

Zaoblení a stíny

border-radius: 20px;          /* zakulacení rohů */
border-radius: 51px;          /* silné = „pilulka“ (tlačítka) */
border-radius: 20px 20px 0 0; /* pořadí: levý-horní, pravý-horní, pravý-dolní, levý-dolní */
box-shadow: 0 4px 12px rgba(0,0,0,.15); /* stín: posun-x posun-y rozostření barva */

12. CSS proměnné (vlastní hodnoty)

Proměnná se definuje v :root (platí pro celou stránku) a používá se přes var(--název).

:root {
  --barva-hlavni: #2e4f21;   /* definice */
  --velikost-nadpisu: 80px;
}

h1 {
  color: var(--barva-hlavni);        /* použití */
  font-size: var(--velikost-nadpisu);
}
Proč: Když chceš změnit barvu, změníš ji na jednom místě. V našem styles.css jsou takto uložené všechny barvy, fonty, velikosti a poloměry.

13. Media queries — responzivita

Media query = „pravidla platí jen na určité šířce okna“. Používáme dvě:

/* Tablet a menší (do 1279px) */
@media (max-width: 1279px) {
  .hero__title { font-size: 58px; }
}

/* Mobil (do 799px) */
@media (max-width: 799px) {
  .hero__title { font-size: 40px; }
  .hero__content { flex-direction: column; } /* text a obrázek pod sebe */
}
Jak to funguje: Základní styly (bez media query) platí pro desktop. Media query je „přebijí“, když je okno užší. Zmenši okno prohlížeče (nebo F12 → ikona telefonu) a uvidíš změny.

14. Pseudotřídy a pseudoprvky

Pseudotřída : = stav prvku. Pseudoprvek :: = část prvku, kterou „dokreslíš“.

.btn:hover { background: green; }    /* :hover = když na něj najede myš */
a:focus-visible { outline: 2px solid; } /* :focus = klávesnicí vybrané (dostupnost) */

.karta::before {        /* ::before = vloží obsah PŘED prvek */
  content: "";          /* povinné, klidně prázdné */
  position: absolute;
  top: 0; left: 0; right: 0;
  height: 1px;          /* vodorovná čárka nad kartou */
  background: #2e4f21;
}
Ukázka :hover — najeď myší
Použití v projektu: Čárky nad kartami v testimonial sekci jsou ::before. Tlačítka mění barvu přes :hover.

15. Carousel bez JavaScriptu (radio + :checked)

Tohle je nejzajímavější trik v projektu. Místo JS použijeme skryté radio buttony a stav :checked.

HTML část:

<input type="radio" name="testimonial" id="t1" checked />
<input type="radio" name="testimonial" id="t2" />

<label for="t1">Karta 1</label>   <!-- klik = zaškrtne radio t1 -->
<label for="t2">Karta 2</label>

<p data-quote="1">Citát 1</p>
<p data-quote="2">Citát 2</p>

CSS část:

/* 1) Radio schováme */
.testimonial__radio { position: absolute; opacity: 0; }

/* 2) Všechny citáty skryjeme */
.testimonial__quote { display: none; }

/* 3) Citát, který patří zaškrtnutému radiu, zobrazíme.
      "~" = obecný sourozenec (najde .testimonial__quote níž v DOM) */
#t1:checked ~ .seznam .testimonial__quote[data-quote="1"],
#t2:checked ~ .seznam .testimonial__quote[data-quote="2"] {
  display: flex;
}
Jak to čteš: „Když je #t1 zaškrtnuté, najdi sourozence .seznam a v něm citát číslo 1 a zobraz ho.“ Kliknutí na <label> zaškrtne radio, čímž se přepne, co je vidět — bez jediného řádku JavaScriptu.

Živá ukázka

Toto je citát pro kartu 1.

Toto je citát pro kartu 2.

Toto je citát pro kartu 3.

Klikni na „Karta 1/2/3“ — přepne se text i zvýraznění. Přesně tak funguje testimonial sekce na webu.

Shrnutí

  • HTML = obsah a význam (nadpisy, odstavce, sekce, obrázky).
  • CSS = vzhled a rozvržení (barvy, mezery, řada/sloupec, responzivita).
  • class pro stylování, id pro jedinečné prvky a kotvy.
  • flex rozvrhuje do řady/sloupce, gap dělá mezery.
  • @media řeší tablet a mobil.
  • Proměnné (--název) drží hodnoty na jednom místě.
  • Carousel jde i bez JS: radio + :checked + ~.
